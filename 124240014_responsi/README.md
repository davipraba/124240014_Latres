# ShoppingHub

Aplikasi Flutter sederhana untuk latihan responsi:

- Login dan registrasi pengguna disimpan di database lokal.
- Daftar produk dan kategori diambil dari [DummyJSON Products](https://dummyjson.com/products).
- Halaman utama menampilkan maksimal 10 produk.
- Tekan produk untuk melihat detailnya dari endpoint `/products/{id}`.
- Filter produk berdasarkan kategori dan simpan produk ke wishlist lokal.
- Akun demo: `admin` dengan password `admin123`.

Jalankan aplikasi dengan `flutter pub get` lalu `flutter run`.
